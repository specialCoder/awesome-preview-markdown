Markdown Preview

Open a Markdown document in a browser tab — a local file:// file or a remote .md URL — then click the toolbar icon, or right‑click the page or a link and choose “Preview markdown on side”.

The browser does the opening; this panel renders whatever the tab shows.

Tip: when the side panel is narrow, use the layout buttons or press F for a wider, fullscreen view.
