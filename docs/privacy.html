Privacy Policy

Awesome Preview Markdown · Chrome extension

← Back to the extension page

TL;DR — Awesome Preview Markdown collects no personal data, makes no network requests, and never stores or transmits the contents of the documents you preview. Everything is rendered locally on your own device.

Last updated: 2026-10-03

What we do

The extension's single purpose is to preview Markdown. When you open a Markdown file, raw URL, or GitHub page in Chrome and choose to preview it, the extension reads the plain text that is already displayed in that tab and renders it as formatted HTML in Chrome's side panel beside the page you were working on.

What we do not do

  • We do not collect, transmit, or store any personally identifiable information.
  • We do not fetch documents on our own or make any network requests. The extension never uploads your files anywhere.
  • We do not read, store, or analyze the content of the Markdown you preview. It is rendered in memory and never leaves your device.
  • We do not track you, run analytics, show advertising, or add any third-party trackers.
  • We do not collect browsing history or search queries.

Local storage

The extension uses chrome.storage only to remember your own interface preferences so they persist between sessions:

  • Theme (light / dark), layout mode, table-of-contents and synced-scrolling toggles, and the splitter position.
  • A short-lived, in-session reference to the tab you are previewing, used only to render that preview. It is cleared automatically and never persisted.

This data stays on your device, is never synced to any server, and is removed when you uninstall the extension.

Permissions

The permissions the extension requests are used solely to deliver the preview described above:

  • contextMenus — to add the "Preview markdown on side" right-click command.
  • sidePanel — to dock the reader beside the current page.
  • scripting — to run one read-only function that reads the already displayed text of the tab you chose to preview.
  • storage — to remember your interface preferences as described above.
  • clipboardWrite — so the "Copy" button on code blocks can copy code text when you click it.
  • Host access — because you may preview Markdown from many sources (local files, raw URLs, GitHub). It is used only to read already-loaded content from the tab you open; the extension does not request data from any site.

Children's privacy

The extension does not knowingly collect any information from anyone, including children. It is a general-purpose document viewer.

Changes to this policy

If this policy changes in a way that affects how data is handled, this page will be updated and the "Last updated" date above will change.
